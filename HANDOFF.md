# Window of Nature website

Live: https://glenngmgm.github.io/windowofnature/
Repository: glenngmgm/windowofnature. GitHub Pages publishes main at the repository root.

## Editing
Static HTML, shared site.css and site.js. Run `python3 gen_pages.py` after editing page content in gen_pages.py. All ten pages are generated: home, rabbit, Shori, hay, pellets, poultry, why-alfalfa, wholesale, feedmill and credits.
